# 🌈 Daddy & Daughter Projects

Educational games and activities we build together.

**To see everything:** double-click `index.html` to open it in your browser.

## 📁 Folders

| Folder | What goes here |
|---|---|
| `index.html` | Home page that shows all our projects |
| `projects-list.js` | The list of projects shown on the home page |
| `projects/` | One folder per project |
| `projects/_template/` | Blank starter: copy it to begin a new project |
| `ideas/` | Our list of things we want to build |
| `shared/` | Images, sounds and styles used by many projects |
| `journal/` | Photos and screenshots from our build days |

## ✨ Starting a new project

1. Copy `projects/_template` and rename it like `2026-12-animal-quiz`
2. Open its `index.html` and change the title
3. Build it together!
4. Fill in its `NOTES.md`
5. Add it to `projects-list.js` so it appears on the home page

## 🌍 Putting it online (later)

This whole folder is already a website, with no extra tools needed. When you're ready:
